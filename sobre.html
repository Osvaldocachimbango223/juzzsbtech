Juzzs Travel & Hospitality

Este projecto foi desenvolvido como trabalho de conclusão de curso, simulando uma plataforma de turismo e hospitalidade sediada em Menongue, Angola. O nosso objectivo é demonstrar competências técnicas e criativas aplicadas ao contexto real do Cuando Cubango.

Objectivo do Projecto

Desenvolver um sistema web de gestão hoteleira e turística que simule operações reais de uma empresa de hospitalidade angolana, aplicando conhecimentos adquiridos ao longo do curso.

🔭

Nossa Visão

Demonstrar capacidade técnica e criativa através deste projecto, preparando-nos para os desafios do mercado de trabalho e contribuindo para o desenvolvimento do sector tecnológico em Angola.

💎

Tecnologias Usadas

O sistema foi construído com HTML5, CSS3 e JavaScript vanilla, utilizando localStorage como base de dados, sem frameworks externas — provando que é possível criar soluções robustas com tecnologias fundamentais.
